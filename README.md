# Paijain India

A production-ready React + Vite + Tailwind architecture scaffold for a premium manufacturing website. All page content is sourced from JSON files and components remain data-driven for future UI implementation.

## Structure

- Public images are organized by section in public/images.
- Page-level components live under src/pages.
- Shared UI and layout live under src/components and src/layouts.
- Content is stored under src/data and can be updated without editing components.

## Scripts

- npm run dev
- npm run build
